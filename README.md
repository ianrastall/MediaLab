# MediaLab
A cross-platform audio and lyric processing laboratory suite.

## Features
- **SongLab**: End-to-end audio mastering pipeline using FFmpeg, SoX, and Rubberband.
- **LyricsLab**: AI-powered vocal transcription and alignment using Whisper, Vosk, and WhisperX.
- **MediaLab.Hub**: Centralized hub connecting all the lab tools.

## Setup
Download the required third-party binaries through the in-app Setup window. They will automatically be placed into a portable `tools` directory alongside the executables.
